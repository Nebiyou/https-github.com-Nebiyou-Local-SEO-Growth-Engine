# Grade 5 Math Mastery — Syllabus (for approval)

A single-file interactive HTML resource covering **everything a 5th grader can be tested
on in any US state (all 50 states + DC, 2025–26)**. Built from state-by-state research
in `STATE-RESEARCH.md`.

**Design principle:** the syllabus is the **union** of all state requirements — the
Common Core grade 5 standards (~45 jurisdictions) form the core, and the topics that
Texas, Virginia, Florida, Minnesota, Oklahoma, South Carolina, Nebraska, and North
Dakota add at grade 5 form the extension units. A student who masters all 8 units is
prepared for the grade 5 math test of **every** state.

## Per-concept deliverables (Phase 2 spec)

Every one of the 23 concepts gets:

1. **"What you need to know"** — the requirement, in kid-friendly language, with the
   standard codes and which states test it.
2. **Animated explainer** — an interactive, step-by-step CSS/JS animation of the
   concept (e.g., watch a decimal shift places when multiplied by 10; watch unit cubes
   fill a prism; watch a fraction bar split for unlike-denominator addition; a spinning
   tree diagram building a sample space). Play/pause/replay controls.
3. **5 multiple-choice questions** — modeled on real state-test formats (4 options,
   with distractors based on common mistakes). Instant feedback with explanations.
4. **5 open-ended questions** — numeric/short-response, like state "equation entry" /
   constructed-response items.
5. **1 "Out of the Box" challenge** — a harder multi-step or puzzle-style problem
   (STAAR/MCAS hard-item difficulty, or one notch above grade level).
6. **Answer key** — every answer with a worked solution, in a collapsible section plus
   a master answer key at the end.

**Totals: 115 multiple-choice + 115 open-ended + 23 challenge problems = 253 questions,
all with worked answers.**

## Implementation plan (Phase 2)

- **One self-contained `grade5-math.html`** — no external libraries, fonts, or network
  calls; works offline; pure HTML/CSS/JS. (Kept separate from the existing Vite app.)
- Sidebar navigation: 8 units → 23 concepts, with progress checkmarks (saved in
  localStorage) as your son completes each quiz.
- Quiz engine: instant scoring for multiple choice, self-check reveal for open-ended,
  hidden-until-clicked answer key.
- Kid-friendly design: bright, readable, large touch targets (works on tablet),
  optional dark mode.
- A "State lens" selector: pick your state to see which concepts are core vs stretch
  for that state's test.

## Suggested build order (after approval)

3. Units 5–6 (measurement & geometry)
4. Units 7–8 (data, probability, financial literacy)
5. Master answer key + polish + QA pass on every animation and answer
